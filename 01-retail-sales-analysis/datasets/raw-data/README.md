
# Raw Dataset

## Dataset Source

This project uses the **Brazilian E-Commerce Public Dataset by Olist**.

The original dataset is publicly available on Kaggle:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Dataset Description

The dataset contains multiple relational tables, including:

- Customers
- Orders
- Order Items
- Products
- Sellers
- Payments
- Reviews
- Product Category Translation

These raw files exceed GitHub's web upload size limit and are therefore not stored in this repository.

## Analysis Workflow

Raw Dataset → Data Cleaning (Excel Power Query) → Exploratory Data Analysis → Power BI Dashboard → Business Insights

The cleaned, analysis-ready dataset created during this project will be available in the **cleaned-data** folder.
